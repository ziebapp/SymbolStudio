# video-production

Reusable AI video production project: Remotion (assembly + motion graphics),
Higgsfield (AI image/video generation), FFmpeg (conversion/delivery).

- First-time setup on a Mac: `bash scripts/setup-mac.sh`
- Check everything works: `npm run verify`
- Open the editor: `npm run studio`
- Shot lists: `compositions/main-film.manifest.ts`, `compositions/main-film-vertical.manifest.ts`

Rules and conventions for Claude: see [CLAUDE.md](CLAUDE.md).
